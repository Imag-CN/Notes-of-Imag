**Ex 3.3:** Suppose $S,T$ are multiplicatively closed, then so do $ST$, and suppose $\varphi: A \to S^{-1}A$. Define the morphism $\phi :  (ST)^{-1}A \to U^{-1}(S^{-1}A)$ as $\phi\left( \frac{a}{st} \right) = \frac{a / s}{\varphi(t)}$. Let $\frac{a_{1}}{s_{1}t_{1}} = \frac{a_{2}}{s_{2}t_{2}}$, then $(a_{1}s_{2}t_{2}-a_{2}s_{1}t_{1})u = 0$ for some $u \in ST$. Meanwhile: $$\phi\left(  \frac{a_{1}}{s_{1}t_{1}} \right) - \phi \left( \frac{a_{2}}{s_{2}t_{2}} \right) = \frac{a_{1} / s_{1}}{\varphi(t_{1})} - \frac{a_{2} / s_{2}}{\varphi (t_{2})} = \frac{a_{1} / s_{1}}{t_{1} / 1} - \frac{a_{2} / s_{2}}{t_{2} / 1}.$$This equals $0$ if and only if $$\left( \frac{a_{1}t_{2}}{s_{1}} - \frac{a_{2}t_{1}}{s_{2}} \right)v = 0 \quad (\exists v \in U),$$equivalently: $$(a_{1}s_{2}t_{2}-a_{2}s_{1}t_{1})tw = 0 \quad (\exists t \in T, w \in S).$$Hence $\phi(x_{1})-\phi(x_{2}) = 0$ if and only if $x_{1} = x_{2}$. "If" part verifies the well-definess, and the "only if" part shows that $\phi$ is injective. For any $\frac{a / s}{u}$, there is some $t \in T$ such that $\varphi(t) = u$, then $\phi\left( \frac{a}{st} \right) = \frac{a / s}{u}$, showing that $\phi$ is surjective.

**Ex 3.4:** **Solution.** Suppose $f: A \to B$ is a homomorphism of rings and let $S$ be a multiplicatively closed subset of $A$. Let $T = f(S)$. Define the morphism $\phi : S^{-1}B \to T^{-1}B,  \phi\left( \frac{b}{s} \right) = \frac{b}{f(s)}$. Let $\frac{b_1}{s_1} = \frac{b_2}{s_2}$. Then $(b_1 s_2 - b_2 s_1)f(u) = 0$ for some $u \in S$. Meanwhile:
$$
\phi\left( \frac{b_1}{s_1} \right) - \phi\left( \frac{b_2}{s_2} \right) = \frac{b_1}{f(s_1)} - \frac{b_2}{f(s_2)}.
$$
This equals $0$ if and only if$$(b_1 f(s_2) - b_2 f(s_1))v = 0 \quad (\exists v \in T),$$equivalently:
$$(b_1 s_2 - b_2 s_1)f(w) = 0 \quad (\exists w \in S).$$
Hence $\phi(x_1) - \phi(x_2) = 0$ if and only if $x_1 = x_2$. The “if” part verifies the well-definedness, and the “only if” part shows that $\phi$ is injective. For surjectivity, for any $\frac{b}{t} \in T^{-1}B$ there exists some $s \in S$ such that $f(s) = t$, then $$\phi\left( \frac{b}{s} \right) = \frac{b}{f(s)} = \frac{b}{t}.$$

*Proof.* The existence follows in the same way as the proof of the existence of maximal ideal by Zorn's Lemma. Now suppose $M \subset A$ being maximal multiplicative. Then for any $x \in A-M$, the set $\cup x^kM$ is closed under multiplication and strictly larger than $M$. It is then forced to be 0 given that $M$ is maximal. Hence $x^n m = 0$ for some $n > 0, m \in M$. Conversely, any $x$ with such property does not lie in $M$, otherwise $0 \in M$. 

Now suppose $x,y \in A-M$, with $x^ns = y^mt = 0$, then $(rx)^ns = r^n x^nm = 0$ for any $r$ and $(x+y)^{n+m}st = 0$. Hence $A-M$ is indeed an ideal. To show the ideal is prime, suppose for contradiction that $ab \in A-M$, with $(ab)^ku = 0$ and $a,b$ both in $M$. Then $0 \in M$, contradiction. Since any prime ideal $\mathfrak{p}$ gives rise to multiplicatively closed set $A-\mathfrak{p}$, $A-M$ is minimal. For the same reason, if $A-M$ is minimal prime ideal, then $M$ is a maximal multiplicative set without 0.

Hence $A-\mathfrak{p} \subsetneq S$, contradiction.
