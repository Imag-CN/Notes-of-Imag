> [!problem]
> For $f: S^1 \to S^1$, $f(z)=z^2$, with notation $\sigma, s, \tau$ as defined, prove that $\sigma^2 - \sigma + s - \tau$ is a 1-boundary in $C_1(S^1)$.

**Proof**:
Note that $\sigma^2 = f \circ \sigma$ and by our parameterization, $\sigma^2 = \tau$ as singular 1-simplices. Thus $\sigma^2 - \tau = 0$.

We need to show $-\sigma + s$ is a boundary.

Construct a singular 2-simplex $c: \Delta^2 \to S^1$ as follows. Identify vertices $v_0, v_1, v_2$ of $\Delta^2$ and define:

$c(v_0) = e^{i(\alpha_0-\delta)}$, $c(v_1) = e^{i(\alpha_0-\delta)}$, $c(v_2) = e^{i(\alpha_0+\delta)}$

Extend linearly on edges:
- $c|_{[v_0,v_1]}$: constant at $e^{i(\alpha_0-\delta)}$ (represents 0-chain)
- $c|_{[v_1,v_2]}$: from $e^{i(\alpha_0-\delta)}$ to $e^{i(\alpha_0+\delta)}$ = $\sigma$
- $c|_{[v_2,v_0]}$: from $e^{i(\alpha_0+\delta)}$ to $e^{i(\alpha_0-\delta)}$ = $s$

The boundary is:
$\partial c = c|_{[v_1,v_2]} - c|_{[v_0,v_2]} + c|_{[v_0,v_1]} = \sigma - s + 0 = \sigma - s$

Therefore $-\sigma + s = -\partial c = \partial(-c)$.

Since $\sigma^2 - \tau = 0$, we have:
$\sigma^2 - \sigma + s - \tau = -\sigma + s = \partial(-c)$

Thus $\sigma^2 - \sigma + s - \tau$ is a 1-boundary. $\square$
